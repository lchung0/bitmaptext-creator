BitmapFont Creator

为 Phaser 游戏开发者打造的高性能位图字体生成工具。用 Rust 编写，快速、可靠、易于集成。

📦 安装使用 📖 查看文档
bitmapfont-creator — zsh
$ cargo install bitmapfont-creator
# 安装完成
$ bitmapfont-creator --config font.json --output ./dist
✓ 生成字体纹理: game-font.png
✓ 生成 XML 描述: game-font.xml
→ 输出目录: ./dist/
$
FEATURES

核心功能

专为游戏开发工作流设计，提供完整的位图字体解决方案

🎨

纹理图集生成

自动将多个字符图片智能合并为单个纹理图集，优化渲染性能，减少 draw call

✂️

精灵表支持

支持从现有精灵表中提取指定帧作为字符，灵活复用已有美术资源

🛡️

智能填充

可配置的字符边距填充，有效防止纹理渗透问题，确保各种缩放下的渲染质量

📄

Phaser 兼容

生成标准的 XML 字体描述文件，与 Phaser 3 BitmapText 完美兼容

📊

JSON 输出

同时输出结构化 JSON 数据，便于程序化处理和与其他工具链集成

⚡

高性能

Rust 原生实现，利用并行处理和高效算法，快速处理大量字符资源

WORKFLOW

使用流程

简单四步，快速集成到您的游戏项目

01

准备资源

准备各字符的 PNG 图片文件，或整理现有精灵表

02

配置映射

创建 JSON 配置文件，定义字符与图片的映射关系

03

执行生成

运行命令行工具，一键生成字体纹理和描述文件

04

集成使用

在 Phaser 中加载生成的字体文件，创建 BitmapText
